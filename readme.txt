==========================================================
 投稿記事一覧（非同期ページネーション付き） 設置ガイド
==========================================================

固定ページにショートコード [pagenation] を書くだけで、投稿記事の一覧を
10件ずつ表示できるようにするパッケージです。


■ ファイル構成
----------------------------------------------------------
  functions-pagenation.php … WordPress用のPHP（ショートコード・非同期取得の処理）
  style.css                … スタイルシート
  script.js                … スクリプト（非同期でのページ切替）
  default_thumb.jpg        … サムネイル未設定の記事に表示するサンプル画像
  index.php               … 表示見本（WordPressには設置しません）
  readme.txt               … このファイル


■ 設置手順
----------------------------------------------------------
※ 親テーマ（Lightning）に直接設置すると、テーマ更新時に消えてしまいます。
   必ず「子テーマ」に設置してください。
   以下、子テーマのフォルダ名を lightning-child として説明します。

1. 子テーマのフォルダ内に「wp-pagenation」フォルダを作成します。

     wp-content/themes/lightning-child/wp-pagenation/

2. 作成したフォルダに、次の4ファイルをFTP等でアップロードします。

     wp-content/themes/lightning-child/wp-pagenation/functions-pagenation.php
     wp-content/themes/lightning-child/wp-pagenation/style.css
     wp-content/themes/lightning-child/wp-pagenation/script.js
     wp-content/themes/lightning-child/wp-pagenation/default_thumb.jpg

   ※ フォルダ名・ファイル名は変更しないでください。
   ※ 子テーマ直下にはテーマ本体の style.css があるため、必ず
      「wp-pagenation」フォルダの中に置いてください（上書き注意）。

3. 子テーマの functions.php の末尾に、次の1行を追記します。
   （管理画面「外観 → テーマファイルエディター」または FTP で編集）

     require_once get_stylesheet_directory() . '/wp-pagenation/functions-pagenation.php';

   ※ functions.php の末尾が「?>」で終わっている場合は、その手前に追記します。
   ※ 記述を誤ると画面が表示されなくなることがあります。
      編集前に functions.php のバックアップを取り、FTPで元に戻せる状態で作業してください。

4. 一覧を表示したい固定ページの編集画面を開き、「ショートコード」ブロックを
   追加して次のように入力し、更新します。

     [pagenation]

5. 固定ページを表示し、記事一覧とページ番号が表示されれば完了です。
   style.css と script.js は、ショートコードを使ったページでのみ自動的に
   読み込まれます（テーマのヘッダー等に link / script タグを書く必要はありません）。


■ 表示内容
----------------------------------------------------------
  ・公開済みの投稿記事を、公開日の新しい順に10件ずつ表示します。
  ・記事ごとに「サムネイル」「日付（YYYY年MM月DD日）」「タイトル」「本文」を表示します。
  ・サムネイルは、投稿時に設定した「アイキャッチ画像」を正方形の枠内に
    全体が収まるように（切り抜かずに）表示します。
    未設定の記事には default_thumb.jpg を表示します。
  ・PC・タブレットでは左にサムネイル、右にテキスト情報を並べた帯状、
    スマートフォン（画面幅575px以下）ではサムネイルの下にテキスト情報を置いた
    カード形式で表示します。
  ・本文はHTMLタグ・画像・ショートコードを除いたテキストのみを表示します。
      - テキストのみで80文字以内      → 本文をそのまま表示
      - 80文字を超える、または画像あり → 80文字まで表示し、末尾に
                                         「...詳しく読む」（投稿記事へのリンク）を表示
  ・ページ番号を押すと、ページを再読み込みせずに一覧が切り替わります。
    1ページ目はページ表示時に出力済みのため、通信は2ページ目以降で発生します。
  ・記事が10件以下の場合、ページ番号は表示されません。
  ・パスワード保護された記事は一覧に表示されません。
  ・「先頭に固定表示」の設定は無視し、公開日順で表示します。


■ カスタマイズ
----------------------------------------------------------
  ・表示件数／本文の文字数
      functions-pagenation.php 冒頭の次の値を変更します。
        define( 'WP_PAGENATION_PER_PAGE', 10 );    … 1ページあたりの件数
        define( 'WP_PAGENATION_BODY_LENGTH', 80 ); … 本文の最大文字数

  ・サムネイル
      未設定時の画像を変えるには、default_thumb.jpg を同じファイル名で差し替えます。
      大きさ・余白部分の背景色は、style.css 冒頭の .pagenation 内の値を変更します。
        --pagenation-thumb-size … サムネイルの一辺（PC・タブレット）
        --pagenation-thumb-bg   … 画像が枠に満たない部分の背景色
      読み込む画像サイズは、functions-pagenation.php 冒頭の次の値を変更します。
        define( 'WP_PAGENATION_THUMB_SIZE', 'medium' );

  ・色
      style.css 冒頭の .pagenation 内の値を変更します。
        --pagenation-text   … タイトル等の文字色
        --pagenation-sub    … 日付・本文の文字色（少し薄い色）
        --pagenation-border … 区切り線の色
        --pagenation-accent … リンク・現在ページの色

  ・ページ切替後のスクロール位置
      切替後は一覧の先頭までスクロールします。固定ヘッダーに隠れる場合は、
      style.css の .pagenation にある scroll-margin-top の値を調整してください。

  ・タイトルから記事へリンクさせたい場合
      仕様どおり、記事へのリンクは「...詳しく読む」のみとしています。
      タイトルにもリンクを付ける場合は、functions-pagenation.php と script.js の
      タイトル出力部分（pagenation__title）を a タグで囲むよう変更してください。


■ うまく表示されないとき
----------------------------------------------------------
  ・[pagenation] という文字がそのまま表示される
      → 手順3の追記がされていない、またはファイルの設置場所が違います。

  ・一覧は出るが、デザインが適用されない／ページ番号が出ない
      → style.css / script.js の設置場所（手順2）を確認してください。
        キャッシュ系プラグインを使用している場合は、キャッシュを削除してください。

  ・ページ番号を押すと「記事の読み込みに失敗しました」と表示される
      → セキュリティ系プラグインやサーバー設定で
        wp-admin/admin-ajax.php へのアクセスが制限されていないか確認してください。

  ・スタイルやスクリプトを修正したのに反映されない
      → ブラウザのキャッシュ、およびキャッシュ系プラグインのキャッシュを削除してください。
